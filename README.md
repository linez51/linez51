### ️ Мой главный проект: VlinkOS

Операционная система, которая защищает сама себя.

**Что внутри:**
- ️ Ядро с Linux-style загрузочной последовательностью
- 🗄️ Реестр в стиле Windows (HKLM, HKCU, HKCR, HKU)
- 🦠 Встроенный антивирус с сигнатурным сканером и карантином
- 📁 Файловая система с пользовательским хранилищем
- 🔐 Система пользователей с root-правами
- 🎮 Встроенные приложения: neofetch, редактор, игры, менеджер пакетов
